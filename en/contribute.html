Contribution guide
  1. Search the collection by title. Existing records welcome additional sources and corrections.
  2. Provide a title, interaction, hardware, platform, and a primary source. Include image provenance and credit.
  3. Maintainers review submissions and prepare the bilingual entry. Contributors can also open a pull request directly.
  4. After review and successful checks, the update is merged, published, and credited.
Good starting tasks include adding a paper link, checking hardware, translating a description, or improving keyboard access.

Automated checks
GitHub Actions runs the following checks for submitted data and code updates. Results appear on pull requests and the Actions page.

Stable IDs, duplicates, required fields, and category values.
Languages and exports

Sources and assets
Source URL structure, local images, and page links.
